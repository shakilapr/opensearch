# Directives

1. **Autonomous Dev**: Never halt on failure. Iterate continuously until tests pass or hard impossibility is proven.
2. **Multi-Strategy**: Formulate and test multiple distinct solutions. Benchmark each before choosing.
3. **Verification**: 100% tests must pass (`test`, `lint`, `build`). Zero regressions.
4. **Clean Commits**: Conventional commits (`feat:`, `fix:`, `test:`); clean working tree.
5. **Terse Style**: Minimal words in replies and comments.
