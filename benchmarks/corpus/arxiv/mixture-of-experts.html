Outrageously Large Neural Networks: The Sparsely-Gated Mixture-of-Experts Layer

A sparsely-gated mixture-of-experts layer routes each input token to only a few expert subnetworks through a learned gating network

Conditional computation lets the model grow to enormous parameter counts while keeping the per-token compute nearly constant

Sparsity in the gate means most experts are dormant for any given example

This scales capacity without a proportional increase in floating point operations.
