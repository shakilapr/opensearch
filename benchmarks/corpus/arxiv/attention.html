Attention Is All You Need

The Transformer is a network architecture that replaces recurrence and convolutions entirely with self-attention

Its core is the scaled dot-product attention mechanism, computed over queries, keys and values

The encoder and decoder are built from stacked multi-head attention layers plus position-wise feed-forward networks

Sinusoidal positional encodings inject order information because there is no recurrence

The model was trained on the WMT 2014 English-to-German translation task and set a new state of the art.
