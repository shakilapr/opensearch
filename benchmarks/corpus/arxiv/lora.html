LoRA: Low-Rank Adaptation of Large Language Models

Low-rank adaptation freezes the pretrained model weights and injects trainable low-rank decomposition matrices into each transformer layer

This drastically reduces the number of trainable parameters and the GPU memory required for fine-tuning

Because the original weights are frozen, LoRA adds no inference latency once the low-rank matrices are merged back

The method matches full fine-tuning quality on many downstream tasks while training a tiny fraction of the parameters.
