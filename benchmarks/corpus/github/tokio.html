tokio - An asynchronous runtime for Rust

Tokio is an asynchronous runtime for the Rust programming language

It provides a multi-threaded, work-stealing scheduler, an event loop backed by epoll or kqueue, and asynchronous I/O primitives

Tasks are spawned with tokio::spawn and driven by futures that implement the Future trait

Install it from the project repository and add the crate to your Cargo.toml.
