Hacker News - Which vector database should I use?

Commenters compare Pinecone, Weaviate, Qdrant, Milvus, pgvector and LanceDB for a side project

Several argue that pgvector is enough if you already run Postgres, while others want dedicated ANN indexes such as HNSW for scale

A recurring complaint is operational overhead: managing yet another service is often the real cost

The consensus for small datasets is to start simple and migrate later.
